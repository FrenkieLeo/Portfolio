# Portfolio

This repository is the durable record for Leo's investing workflow.

It is organized as three connected systems:

- `portfolio/`: IBKR trades, positions, cost basis, realized/unrealized P&L, and return curves.
- `tradingplan/`: planned entries, stop losses, targets, review status, and alert state.
- `valuation/`: company valuation tables extracted from screenshots or manually entered research.
- `dashboard/`: data contract for a future visual dashboard.
- `sync_log/`: dated sync notes and change logs.
